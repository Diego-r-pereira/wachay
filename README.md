# WACHAY - Forest Fire Detection & Early Warning System

WACHAY is an integrated platform for forest fire detection, real-time risk assessment, operational ranger dispatch, and citizen reporting designed for the Tunari National Park and Cochabamba region.

## Project Structure

```
wachay/
├── backend/    # FastAPI REST API, ML Inference, RAG & WhatsApp/Telegram Services
├── frontend/   # React (Vite + TypeScript + Tailwind CSS) Web Dashboard
└── mobile/     # React Native (Expo + TypeScript) Mobile App
```

## Branch Strategy

- **`main`**: Full project repository containing all modules.
- **`backend`**: Standalone backend service source code.
- **`frontend`**: Standalone web frontend application source code.
- **`mobile`**: Standalone mobile application source code.
- **`backup-completo`**: Repository backup branch.
