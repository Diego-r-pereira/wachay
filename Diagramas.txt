# =============================================================================
# 2. DIAGRAMA DE SECUENCIA: REGISTRO Y DETECCIÓN EN CAMPO (APLICACIÓN MÓVIL)
# =============================================================================

```mermaid
sequenceDiagram
    autonumber
    actor Ciudadano as Ciudadano (App Movil)
    participant AppMovil as App React Native (Expo)
    participant Backend as FastAPI Backend
    participant WeatherAPI as OpenWeatherMap API
    participant Notif as Servicios Mensajeria (Twilio/Telegram)

    Ciudadano->>AppMovil: Abre Formulario de Denuncia
    AppMovil->>AppMovil: Obtiene GPS (expo-location)
    AppMovil->>AppMovil: Abre Camara y toma fotografia
    AppMovil->>AppMovil: Comprime foto a 150 KB (expo-image-manipulator)
    
    alt Con Conexion a Internet
        AppMovil->>Backend: POST /api/mobile/register_report (JSON + photo_base64)
        Backend->>WeatherAPI: Solicita Clima en coordenadas (Lat/Lon)
        WeatherAPI-->>Backend: Temperatura, Viento, Humedad
        Backend->>Backend: Guarda en SQLite (Estado: Citizen_Pending)
        Backend-->>AppMovil: Retorna tracking_code (Ej: WCY78349)
        AppMovil-->>Ciudadano: Muestra pantalla de exito con codigo de rastreo
    else Sin Conexion a Internet (Modo Offline)
        AppMovil->>AppMovil: Encola reporte en AsyncStorage local
        AppMovil-->>Ciudadano: Alerta "Sin Red: Reporte guardado localmente"
        Note over Ciudadano, AppMovil: Al recuperar cobertura de internet...
        Ciudadano->>AppMovil: Clic en "[Sincronizar]"
        AppMovil->>Backend: Sube lote de reportes encolados
        Backend-->>AppMovil: Retorna codigos de seguimiento generados
    end
```

# =============================================================================
# 3. DIAGRAMA DE SECUENCIA: APROBACIÓN Y ALERTAS EN LA WEB (ADMINISTRADOR)
# =============================================================================

```mermaid
sequenceDiagram
    autonumber
    actor Admin as Administrador (Web)
    participant WebApp as Web React 19 (Vite)
    participant Backend as FastAPI Backend
    participant DB as SQLite (WAL)
    participant Notif as Servicios Mensajeria (Twilio/Telegram)

    Admin->>WebApp: Inicia sesion (/api/auth/login)
    WebApp-->>Admin: Muestra Panel de Administracion
    Admin->>WebApp: Accede a pestaña "Reportes Ciudadanos Pendientes"
    WebApp->>Backend: GET /api/reports/ (Filtra Citizen_Pending)
    Backend-->>WebApp: Retorna lista con fotos Base64 y datos
    Admin->>WebApp: Selecciona reporte y presiona "Aprobar"
    WebApp->>Backend: PUT /api/reports/{id} (status = First_State)
    Backend->>DB: Actualiza estado del reporte
    
    Note over Backend, Notif: Ejecucion asincrona via BackgroundTasks (FastAPI)
    Backend->>Notif: Dispara mensaje Twilio WhatsApp a Rangers
    Backend->>Notif: Dispara mensaje Telegram Bot a canal SERNAP
    
    Backend-->>WebApp: HTTP 200 OK (Reporte Aprobado)
    WebApp-->>Admin: Actualiza lista y remueve reporte de la bandeja
```

# =============================================================================
# 4. DIAGRAMA DE SECUENCIA: ASISTENTE DE EMERGENCIAS (RAG)
# =============================================================================

```mermaid
sequenceDiagram
    autonumber
    actor Guardaparques as Ranger (Web)
    participant WebApp as Web React
    participant Backend as FastAPI Backend
    participant RAG as RAG Service (TF-IDF)
    participant Gemini as Gemini AI API

    Guardaparques->>WebApp: Escribe pregunta (Ej: "¿Como actuar ante fuego forestal en Tunari?")
    WebApp->>Backend: POST /api/ml/ask-ai (message)
    Backend->>RAG: Extrae pasajes relevantes del manual SERNAP
    RAG-->>Backend: Fragmentos de contingencia localizados
    
    alt Backend Online (Conexion a Google Cloud)
        Backend->>Gemini: Envia prompt (Pasajes de contexto + Mensaje original)
        Gemini-->>Backend: Genera respuesta enriquecida sin alucinaciones
        Backend-->>WebApp: Retorna respuesta de Gemini (Modo: nubarron/gemini)
    else Backend Offline (Sin conexion a Internet)
        Backend-->>WebApp: Retorna los pasajes directos del manual (Modo: local/TF-IDF)
    end
    WebApp-->>Guardaparques: Muestra respuesta en chat
```
